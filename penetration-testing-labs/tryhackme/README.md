# TryHackMe Labs

Authorized TryHackMe training environments used to practice Windows and web penetration-testing techniques.

## Featured Labs

- **[Blue](./blue.md)** — SMB enumeration, MS17-010/EternalBlue and Windows privilege escalation
- **Ice** — Icecast service enumeration, vulnerability research and Windows post-exploitation
- **[Ignite](./ignite.md)** — Fuel CMS enumeration, web exploitation and Linux privilege escalation

Individual write-ups are sanitized to exclude credentials, flags, target-specific sensitive information, and unnecessary exploit secrets.
