# TryHackMe Labs

Authorized TryHackMe training environments used to practice Windows and web penetration-testing techniques.

## Labs

- **Blue** — SMB enumeration, MS17-010/EternalBlue and Windows privilege escalation
- **Ice** — Icecast service enumeration, vulnerability research and Windows post-exploitation
- **Ignite** — Fuel CMS enumeration, web exploitation and Linux privilege escalation

Individual write-ups will be added after sanitizing credentials, flags, target-specific sensitive information, and unnecessary exploit secrets.
