# VulnHub Labs

Authorized vulnerable-machine labs used to practice reconnaissance, enumeration, exploitation, and privilege escalation.

## Labs

- **DC-1** — Drupal reconnaissance and SUID `find` privilege escalation
- **DC-2** — WordPress enumeration, credential testing, SSH and restricted-shell analysis
- **DC-3** — Joomla reconnaissance, SQL injection and post-exploitation
- **Raven** — WordPress enumeration, SSH and sudo/Python privilege escalation
- **Cybersploit 1** — Web/network enumeration and exploitation workflow
- **Cybersploit 2** — Linux enumeration and Docker privilege escalation
- **Vegeta** — Web enumeration, source analysis and multi-stage clue discovery

Individual write-ups will be added after sanitizing credentials, flags, target-specific sensitive information, and unnecessary exploit secrets.
