# Penetration Testing Labs

Hands-on write-ups from authorized cybersecurity training environments and vulnerable lab machines.

## Methodology

Typical workflow used across the labs:

1. Information gathering
2. Port and service enumeration
3. Web/application enumeration
4. Vulnerability identification and research
5. Initial access
6. Privilege escalation
7. Post-exploitation analysis
8. Documentation and lessons learned
